border-radius test

Radius values used throughout, applied consistently across border styles so results are directly comparable:

  • 30px -- uniform circular corners
  • 25% 10% -- uniform elliptical corners (two values: horizontal / vertical)
  • 10% 30% 50% 70% -- four distinct corner radii (top-left, top-right, bottom-right, bottom-left)
  • 10% / 50% -- small horizontal radius, large vertical radius (slash syntax)
  • 10px 100px / 120px -- the vertical radius (120px on all four corners) exceeds the 120px box height, so the radii must be scaled down per the CSS corner-overlap rules
  • 50% 20% / 10% 40% -- four distinct corners, independently elliptical
  • 20% 0% 20% 0% / 0% 20% 0% 20% -- checkerboard of sharp and round corners, to check that a sharp corner next to a round one doesn't bleed

corner geometry

no border: class="none"

Full radius set, so the clip shape can be checked with nothing else (border shading, dashing) in the way.

solid border: class="plain"

border: 5px solid black -- uniform single-ring border, the simplest non-empty case.

clamped radius on a narrow box

A 40×120px box where the requested radius is at least half the smaller dimension, forcing a clamp to a full capsule (pill) shape.

border style variants

dotted border: class="dotted" (border-radius not yet supported)

A dotted side falls back to the legacy square-corner border renderer, so every border-radius below is silently ignored.

dashed border: class="dashed" (border-radius not yet supported)

A dashed side falls back to the legacy square-corner border renderer, so every border-radius below is silently ignored.

double border: class="double"

border: 12px double #2a6 -- two concentric rings.

double border, mixed width per side: class="double mixed-width"

border-width: 4px 20px 8px 14px on top of the double style above.

double border, mixed width and color per side: class="double mixed-width mixed-color"

Combines mixed per-side width and per-side color with the double style -- the most demanding corner case for the mitred-band geometry.

groove border: class="groove"

border: 12px groove #2a6 -- shaded two-tone ring.

ridge border: class="ridge"

border: 12px ridge #2a6 -- shaded two-tone ring.

inset border: class="inset"

border: 12px inset #2a6 -- shaded mitred ring.

outset border: class="outset"

border: 12px outset #2a6 -- shaded mitred ring.

mixed style per side: class="mixed-style"

top solid red / right dashed green / bottom dotted blue / left double purple -- the corner miter between very different styles.

mixed width per side: class="mixed-width"

same solid style and color on all sides, different width per side -- tapered corner geometry.

mixed color per side: class="mixed-color"

same solid style and width on all sides, different color per side -- the corner miter's color transition.

alternating dashed/dotted per side: class="alternating" (border-radius not yet supported)

same width and color on all sides, alternating dashed/dotted style per side.

Every side here is dashed or dotted, so the box falls back to the legacy square-corner border renderer and every border-radius below is silently ignored.

solid sides + one fully-transparent dashed side: class="transparent-dashed-side"

top/bottom/left solid black, right dashed with transparent color -- the dashed side paints nothing, so it should be treated the same as "no border" on that side, and the background fill should follow the rounded corner exactly like the border does.

Regression check: a transparent dashed/dotted side must not make the box fall back to a square background fill while the border is still drawn rounded -- the background's corners must not poke out past the border's curve.

partial borders

adjacent sides only: class="adjacent"

right + bottom only, top and left have no border at all.

adjacent sides only, mixed color: class="adjacent mixed-color"

right + bottom borders in different colors -- checks the miter where one of the two mitred sides is missing entirely.

opposite sides only: class="opposite"

top + bottom only, no left/right border at all.

opposite sides only, mixed color: class="opposite mixed-color"

top + bottom borders in different colors, with no side borders to miter against.

border-radius + background-image, tiled (not yet supported)

Each box has a repeating 20×20 red/yellow checkerboard tile as its background, layered under the border. The image should be clipped to the same rounded box the border-radius describes: the border's inner curve where a border is drawn, or the box's own outer curve where it isn't.

Any element with a background-image falls back to the legacy square-corner border renderer, so every border-radius in this section is silently ignored and the image is painted as a plain rectangle.

border-radius + background-image, single (no-repeat, cover) (not yet supported)

Each box has a single 160×120 image of four asymmetric colored quadrants (red/green/blue/purple) with an off-center orange circle (background-repeat: no-repeat; background-size: cover; background-position: center;). The irregular, non-repeating layout makes it obvious at a glance whether the image was scaled to fit or accidentally tiled -- a periodic pattern like stripes can look the same either way.

Any element with a background-image falls back to the legacy square-corner border renderer, so every border-radius in this section is silently ignored and the image is painted as a plain rectangle.
